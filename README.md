# Default-Payments-of-Credit-Card-
Default Payments of Credit Card Clients in Taiwan from 2005
Default Payments of Credit Card Clients (Taiwan, 2005)

Power BI analysis and visualization of the UCI "Default of Credit Card Clients" dataset, exploring patterns in customer default behaviour across demographic, credit, and repayment history variables.

Overview

This project visualizes credit card default data for clients in Taiwan (2005), highlighting key drivers of default risk such as credit limit, payment history, age, education, and marital status.

Contents

Dataset
Source: UCI Machine Learning Repository — Default of Credit Card Clients Dataset
~30,000 records of Taiwanese credit card clients (2005)
Features: demographic info (sex, education, marriage, age), credit data (limit balance), repayment status (Apr–Sep 2005), bill amounts, and payment amounts
Target: default payment next month (binary)
Tools
Power BI (data modeling, DAX, dashboard visuals)
Key Analysis
Default rate breakdown by demographic segment (age, sex, education, marital status)
Credit limit vs. default likelihood
Repayment status trends across months
Bill amount vs. payment amount patterns
