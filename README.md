Exploratory data analysis and logistic regression model to predict credit card payment default, using the UCI "Default of Credit Card Clients" dataset.

Overview

This project analyzes credit card client data from Taiwan (2005) to identify key drivers of default risk and builds a logistic regression model to predict whether a client will default on their next payment.
